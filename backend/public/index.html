Everything you'd actually reach for

Multi-host + groups

Save as many servers as you run, sorted into groups instead of one endless list.

// sync from your computer

Publish SSH keys straight from your terminal

The termul agent reads your ~/.ssh/config, lets you pick which hosts to send, then shows one QR code per host — scan it in the app. Nothing touches the network; the QR code is the only thing that leaves your screen.

// security

Not just a "secure" badge. Here's how:

Instead of "bank-level encryption," here's exactly what happens behind the scenes.

✓ Passwords & keys Stored in the OS's own secure storage (Keychain on iOS, Keystore on Android) — never a plain file.
✓ SSO login Standard OAuth2 Authorization Code Grant — the code-for-token exchange runs on a backend, never inside the app.
✓ Client secret Never compiled into the APK, so it can't be pulled out of the app binary.
✓ Hosts & groups 100% local on your device — no server holds that data yet (cross-device sync is on the roadmap).
